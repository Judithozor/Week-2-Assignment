Part D — What I Learned

  1. What does the action attribute do?
    The action attribute tells the browser where to send the form when it is submitted — it points to the URL or server endpoint that will process the form (e.g. /register).
  2. What does the method attribute do?
    The method attribute defines how the form data is sent to the server. It is usually set to either get or post.
  3. Why is GET commonly useful for a search form?
    GET appends the form data to the URL as query parameters, which makes search results easy to bookmark, share, or revisit, and it works well for requests that only retrieve information rather than change anything on the server.
  4. Why might POST be used for aregistration form?
    POST sends form data in the body of the HTTP request instead of the URL, which is better suited for sensitive or larger amounts of data like passwords and personal details, and it does not clutter or expose the data in the browser's address bar.
  5. Does using POST automatically make information secure?
    No. POST only hides the data from the URL — it does not encrypt it. The data can still be intercepted if the connection isn't secured with HTTPS. True security requires HTTPS, proper server-side validation, and safe handling of the data once it's received.
